    Sync to Google Sheets
    1. Open the Google Sheet you want activities to land in.
    2. Menu: Extensions → Apps Script. A new tab opens.
    3. Delete whatever's in the editor and paste the script below.
    4. Click the disk Save icon, name the project anything.
    5. Click Deploy → New deployment.
    6. Click the gear icon → choose Web app.
    7. Set Execute as: Me. Who has access: Anyone. Click Deploy.
    8. Authorize when prompted (advanced → "Go to (your project name) (unsafe)" — it's your own script).
    9. Copy the Web app URL and paste it back here, then flip the toggle on. Hit Send test row to verify.
